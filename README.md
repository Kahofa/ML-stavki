# ML-stavki — вероятностные прогнозы футбольных матчей

Система строит **откалиброванные вероятности** (1X2, тотал 2.5, «обе забьют», топ-3 счёта) на все матчи
заданной даты, сравнивает их с рынком, считает value и размер ставки по ¼ Келли — и **до любых прогнозов**
прогоняет walk-forward бэктест, честно показывая, лучше ли модель рынка.

> Правило №1: данные не выдумываются. Нет матчей / коэффициентов / составов из API — матч помечается
> `LOW DATA` (или прогноз не строится вовсе), уверенность понижается. Время загрузки каждого источника
> пишется в SQLite и выводится в отчёт.

## Архитектура

```
main.py                CLI
pipeline.py            оркестрация: данные → признаки → бэктест → прогнозы на дату (live / replay)
config.py              лиги и их id в каждом источнике, параметры моделей и ставок, ключи из .env
data/
  cache.py             SQLite: HTTP-кэш, журнал источников (fetched_at), снимки коэффициентов
  http.py              GET с кэшем, паузами, ретраями (429/5xx), «предохранителем» для недоступных хостов
  history.py           история football-data.co.uk + ClubElo, нормализация сезонов и названий
  api_football.py      матчи дня, составы, травмы, таблицы, недавние результаты
  football_data_org.py резервный источник расписания
  odds_api.py          коэффициенты нескольких букмекеров, снимки → закрывающая линия (CLV)
  understat.py         xG матчей и игроков
  clubelo.py           ClubElo для сверки с собственным Elo
  teams.py             сопоставление названий команд между источниками
features/
  elo.py               собственный Elo (поле, разница мячей, регрессия к среднему между сезонами)
  team_form.py         xG/xGA за 5 и 10 матчей (дом/выезд) с экспоненциальным затуханием, отдых,
                       плотность календаря, таблица до даты матча, мотивация, дерби
  injuries.py          вес отсутствующих игроков по минутам и вкладу в xG+xA
  builder.py           единый расчёт признаков для истории и матчей дня (без утечки будущего)
models/
  dixon_coles.py       Dixon-Coles с затуханием по времени и ridge-априорами → матрица счетов
  elo_model.py         Elo → 1X2 (ordered logit)
  gbm.py               LightGBM на признаках
  market.py            удаление маржи: Шин, power, мультипликативный
  ensemble.py          линейный пул, веса по минимуму log-loss на валидации
  calibration.py       isotonic / Platt / без калибровки (выбор по CV), reliability diagram
  decision.py          value, ¼ Kelly c потолком 2%, уровень уверенности, фильтр нереальных цен
backtest/
  walkforward.py       посезонный walk-forward, симуляция ставок
  metrics.py           log-loss, Brier, accuracy, ROI, CLV, bootstrap-ДИ ROI
report/
  render.py            CSV + HTML, текстовая сводка
  templates/report.html.j2
tests/                 31 тест ключевых функций (без сети)
```

Поток данных:

```
football-data.co.uk (история, коэффициенты) ─┐
API-Football / football-data.org (матчи) ────┤
Understat (xG) · ClubElo · The Odds API ─────┤→ SQLite-кэш → признаки → Dixon-Coles (OOS, еженедельно)
                                             │                       → Elo-ordinal, LightGBM (OOS по сезонам)
                                             │                       → рынок (Шин)
                                             └→ ансамбль (веса на S-2..S-1) → калибровка → value/Kelly → отчёт
```

## Источники и лимиты бесплатных тарифов

| Источник | Что берём | Бесплатно | Ключ |
|---|---|---|---|
| [API-Football](https://www.api-football.com/) (api-sports.io) | матчи дня, составы, травмы, таблицы, результаты после даты обновления истории, КПЛ | 100 запросов/сутки; на free-тарифе доступ к сезонам может быть ограничен — проверьте в дашборде | `API_FOOTBALL_KEY` |
| [football-data.org](https://www.football-data.org/) | резервное расписание | 10 запросов/мин, 12 турниров (нет РПЛ/КПЛ), без коэффициентов | `FOOTBALL_DATA_ORG_KEY` |
| [The Odds API](https://the-odds-api.com/) | 1X2 и тотал у многих букмекеров | 500 кредитов/мес; запрос `/odds` стоит рынки × регионы (h2h,totals × eu,uk = 4); `/sports` бесплатно; исторические снимки — только платно | `ODDS_API_KEY` |
| [Understat](https://understat.com/) | xG матчей и игроков (АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1, РПЛ) | официального API нет; кэш + пауза 3 с | — |
| [ClubElo](http://clubelo.com/) | рейтинги для сверки | без ключа, кэш 12 ч | — |
| [football-data.co.uk](https://www.football-data.co.uk/) | история результатов, ударов, коэффициентов Bet365 и максимальных по ~17 букмекерам | бесплатно; используется зеркало `xgabora/Club-Football-Match-Data` на GitHub (данные до 03.09.2026) | — |

FBref как альтернатива Understat не реализован (у Sports Reference жёсткий лимит ~10 запросов/мин и блокировка
при превышении). Погода не используется: признака нет в истории, поэтому проверить его вклад бэктестом нельзя.
Судья выводится в карточке матча информационно.

### Как получить ключи
1. API-Football: зарегистрироваться на <https://dashboard.api-football.com/register>, ключ — в разделе Account.
2. football-data.org: <https://www.football-data.org/client/register>, ключ приходит на почту.
3. The Odds API: <https://the-odds-api.com/#get-access>, ключ приходит на почту.
4. `cp .env.example .env` и вписать ключи. `.env` в `.gitignore`.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env            # вписать ключи
python main.py                  # сегодня (Asia/Almaty), приоритетные лиги: EPL, LaLiga, SerieA, Bundesliga, Ligue1, RPL, KPL
python main.py --date 2026-10-31 --leagues EPL,LaLiga --refresh
python main.py --all-leagues    # + Championship, Eredivisie, Primeira, BelgiumPro, SuperLig, Scotland
python main.py --date 2026-08-29 --replay   # ретро-прогноз на прошедшую дату по реальным данным
python main.py --backtest-only
pytest -q
```

Результаты — в `output/`: `report_<дата>.html`, `predictions_<дата>.csv`, `markets_<дата>.csv`,
`backtest_summary.json`, `backtest_by_season.csv`, `backtest_bets.csv`, `reliability_diagram.png`.

Запуск занимает ~4–5 минут: каждый раз заново строятся признаки и walk-forward бэктест
(≈3000 подгонок Dixon-Coles), потому что прогноз на дату — это последний шаг того же бэктеста.

**Закрывающая линия / CLV.** Каждый запрос к The Odds API сохраняется в `odds_snapshots`. Запустите систему
ещё раз за 5–15 минут до начала матчей (`--refresh`) — последний снимок до стартового свистка станет
закрывающей линией, и CLV появится в отчёте.

## Методология

* **Без заглядывания в будущее.** Матчи дня добавляются в общий DataFrame без результата, и все признаки
  (Elo, форма, таблица) считаются по матчам строго раньше даты. Dixon-Coles переобучается раз в неделю на
  матчах до даты переобучения (и отдельно на дату прогноза). Elo-ordinal и LightGBM для сезона S обучаются на
  сезонах < S, веса ансамбля и калибратор — на OOS-прогнозах сезонов S-2 и S-1.
* **xG.** Если Understat доступен — реальный xG. Иначе xG-прокси по ударам (удары в створ / мимо), коэффициенты
  для каждой лиги и сезона подбираются по двум предыдущим сезонам (у football-data.co.uk менялось определение
  «удара в створ», например в АПЛ до 2013/14). В отчёте указано, какой xG использован. У РПЛ ударов в
  датасете нет — признаки xG для неё пустые.
* **Рынок.** Bet365 (в истории) или Pinnacle/медиана по букмекерам (live), маржа удаляется методом Шина
  (1X2) и power (тотал). Лучшая цена берётся по всем букмекерам, но котировки выше референсной более чем
  на 15% отбрасываются как ошибочные: в датасете встречаются «max» 2.25 при рыночных 1.50.
* **Уверенность.** HIGH — полнота данных ≥ 85%, расхождение DC/Elo/GBM σ ≤ 0.05, разрыв с рынком ≤ 6 п.п.
  LOW — LOW DATA, полнота < 60%, σ > 0.10, нет рынка или разрыв > 12 п.п. Остальное — MEDIUM.
* **Ставка.** value = p × odds − 1 > 3%, уверенность ≥ MEDIUM, коэффициент 1.30–8.0; размер = ¼ Келли, не
  больше 2% банка. На матч — не больше одной ставки на рынок (1X2 / тотал).
* **Травмы и составы.** Корректировка ожидаемых голов DC по доле отсутствующих в xG+xA и минутах команды
  (±15% максимум). Исторических данных о травмах нет, поэтому **этот блок не проверен бэктестом** — это
  эвристика, и в отчёте она указана отдельно.

## Ограничения

* Прогноз на сегодня требует ключей API и сетевого доступа к их хостам. Без них система всё равно
  прогоняет бэктест и честно пишет, что матчи дня получить не удалось.
* Исторический датасет обновляется вручную автором зеркала (последний матч — 03.09.2026). Разрыв до
  текущей даты закрывается результатами API-Football; без него матчи с устаревшей историей помечаются LOW DATA.
* Для КПЛ нет ни истории в датасете, ни линии в The Odds API: прогнозы только по моделям, уверенность LOW.
* Еврокубки в истории отсутствуют. Плотность календаря считается только по матчам лиги.

Вероятности — это оценки, а не гарантии. Ставки связаны с риском потери денег.
